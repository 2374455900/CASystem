## 🛠️ 故障排查

### 应用无法启动

**检查端口占用：**
```bash
netstat -ano | findstr :8088
```

**解决方法：**
```bash
# 修改端口
server.port=8089
```

### 数据库连接失败

**检查 MySQL 服务：**
```bash
mysql -u root -p -e "SHOW DATABASES;"
```

**检查配置：**
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/schedule_system
    username: root
    password: <your_password>
```

### 邮件发送失败

**查看日志：**
```
WARN  CertificateReminderService - 邮件服务未启用
```

**解决方法：**
配置 SMTP 用户名和密码
