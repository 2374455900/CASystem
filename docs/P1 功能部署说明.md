## 三、配置说明

### 1. 邮件服务配置（可选）

在 `application.yml` 或环境变量中配置：

```yaml
app:
  mail:
    enabled: true  # 启用邮件服务
    from: noreply@casystem.com
    smtp-host: smtp.qq.com
    smtp-port: 587
    username: your-email@qq.com
    password: your-auth-code  # 使用授权码，不是密码
```

**获取 QQ 邮箱授权码：**
1. 登录 QQ 邮箱
2. 设置 → 账户
3. 开启 POP3/SMTP 服务
4. 生成授权码

### 2. 提醒天数配置

```yaml
app:
  reminder:
    days-before-expiry: 30,15,7  # 到期前 30 天、15 天、7 天提醒
```

## 五、功能测试

### 1. 测试 MFA

**步骤 1：初始化 MFA**
```bash
curl -X POST http://localhost:8088/api/mfa/setup \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json"
```

**响应示例：**
```json
{
  "code": 200,
  "message": "MFA 初始化成功",
  "data": {
    "secret": "JBSWY3DPEHPK3PXP",
    "qrCodeUri": "otpauth://totp/CaSystem:user@example.com?secret=JBSWY3DPEHPK3PXP&issuer=CaSystem",
    "manualEntryKey": "JBSWY3DPEHPK3PXP"
  }
}
```

**步骤 2：使用认证器扫描二维码**
- 打开 Google Authenticator、Microsoft Authenticator 或 Authy
- 扫描二维码或手动输入密钥
- 获取 6 位验证码

**步骤 3：验证并启用**
```bash
curl -X POST http://localhost:8088/api/mfa/setup/verify \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{"code": "123456"}'
```

**步骤 4：查询状态**
```bash
curl -X GET http://localhost:8088/api/mfa/status \
  -H "Authorization: Bearer <your_token>"
```

### 2. 测试证书验证工具

**解析证书：**
```bash
curl -X POST http://localhost:8088/api/tools/parse \
  -F "file=@/path/to/certificate.cer"
```

**检查证书状态：**
```bash
curl -X POST http://localhost:8088/api/tools/check-status \
  -F "file=@/path/to/certificate.cer"
```

### 3. 测试证书到期提醒

**查看日志：**
等待定时任务执行（每天早上 9:00），或查看日志：
```

INFO  CertificateReminderService - 发送证书到期提醒邮件成功
```

## 七、常见问题

### 1. MFA 密钥保存

**问题：** MFA 密钥是否需要加密存储？

**回答：** 当前版本使用明文存储（Base32 编码），生产环境建议：
- 使用数据库加密字段
- 或使用密钥管理服务（KMS）
- 或使用硬件安全模块（HSM）

### 2. 邮件发送失败

**问题：** 邮件发送失败怎么办？

**排查步骤：**
1. 检查 SMTP 配置是否正确
2. 确认使用授权码而非密码
3. 检查防火墙是否开放端口
4. 查看应用日志获取详细错误信息

**临时方案：** 设置 `app.mail.enabled: false` 禁用邮件功能

### 3. 定时任务不执行

**问题：** 证书到期提醒定时任务不执行？

**检查：**
1. 确认 `@EnableScheduling` 已添加
2. 检查应用日志是否有定时任务执行记录
3. 确认服务器时间是否正确

**手动触发：** 可以创建临时 API 接口手动触发提醒

### 4. 证书验证失败

**问题：** 证书解析或验证失败？

**检查：**
1. 确认证书格式（支持 DER/PEM）
2. 检查证书文件是否完整
3. 查看错误日志获取详细信息

## 八、安全建议

### 1. MFA 使用建议

- ✅ 建议管理员账户强制启用 MFA
- ✅ 关键操作（证书吊销、密钥导出）要求 MFA 验证
- ✅ 提供 MFA 备用码功能（防止手机丢失）
- ✅ 定期提醒用户检查 MFA 状态

### 2. 邮件安全

- ✅ 使用 SMTPS（SSL/TLS）加密连接
- ✅ 不要硬编码密码，使用环境变量
- ✅ 配置邮件发送频率限制
- ✅ 添加邮件签名 DKIM/SPF

### 3. 审计日志

- ✅ 定期备份审计日志（建议保留 6 个月）
- ✅ 限制审计日志访问权限
- ✅ 敏感信息脱敏处理
- ✅ 集成日志分析工具

## 九、性能优化建议

### 1. 定时任务优化

