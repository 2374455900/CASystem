## 🔧 技术栈

### 后端
- Spring Boot 3.2.0
- Spring Security + JWT
- Spring Data JPA
- MySQL 5.7
- Bouncy Castle 1.78
- Apache Commons Codec

### 前端
- Vue.js / React (根据实际项目)
- Axios
- 响应式设计

### 安全
- BCrypt 密码加密
- TOTP 双因子认证
- RSA 2048 + SHA256withRSA
- X.509 v3 证书
