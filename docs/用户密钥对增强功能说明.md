# 用户密钥对增强功能说明

**创建日期：** 2026-04-13  
**功能：** 为每个用户生成独立的密钥对  
**模式：** 增强模式（方案 B）

---

## 📋 架构说明

### 增强模式架构

```
CA 机构
├── CA 私钥 (PrivateKey.pem) - CA 持有，用于签发证书
└── CA 公钥 (PublicKey.pem) - 公开分发，用于验证证书

用户 A
├── 用户 A 私钥 - 用户自己保管（加密存储）
├── 用户 A 公钥 - 包含在证书中
└── 用户 A 证书
    ├── 用户 A 信息
    ├── 用户 A 公钥
    └── CA 签名（使用 CA 私钥签名）

用户 B
├── 用户 B 私钥 - 用户自己保管（加密存储）
├── 用户 B 公钥 - 包含在证书中
└── 用户 B 证书
    ├── 用户 B 信息
    ├── 用户 B 公钥
    └── CA 签名（使用 CA 私钥签名）
```

### 密钥对用途

| 密钥 | 持有者 | 用途 |
|------|--------|------|
| **CA 私钥** | CA 机构 | 签发和签署用户证书 |
| **CA 公钥** | 公开 | 验证用户证书上的 CA 签名 |
| **用户私钥** | 用户自己 | 用户签名数据、解密数据 |
| **用户公钥** | 包含在证书中 | 验证用户签名、加密数据发送给用户 |

## ✅ 实现功能

### 1. 自动生成用户密钥对

**实现类：** `UserKeyService`

**功能：**
- 为每个申请证书的用户生成独立的 RSA 密钥对
- 密钥长度：2048 位（可配置）
- 算法：RSA（可扩展支持 EC 等）

**代码示例：**
```java
@Service
public class UserKeyService {
    public KeyPairInfo generateUserKeyPair(String algorithm, int keySize) {
        // 生成密钥对
        KeyPairGenerator keyPairGenerator = KeyPairGenerator.getInstance(algorithm);
        keyPairGenerator.initialize(keySize);
        KeyPair keyPair = keyPairGenerator.generateKeyPair();
        
        // 转换为 PEM 格式
        String publicKeyPem = encodePublicKeyToPem(keyPair.getPublic());
        String privateKeyPem = encodePrivateKeyToPem(keyPair.getPrivate());
        
        return new KeyPairInfo(publicKeyPem, privateKeyPem, algorithm, keySize);
    }
}
```

### 2. 证书申请流程更新

**修改内容：**
1. 用户申请证书时，系统自动生成用户密钥对
2. 用户公钥嵌入到证书中
3. 用户私钥加密存储到数据库

**流程：**
```
1. 用户提交证书申请
   ↓
2. 系统生成用户密钥对（RSA 2048）
   ↓
3. 使用用户公钥生成证书
   ↓
4. 证书包含：
   - 用户信息
   - 用户公钥
   - CA 签名
   ↓
5. 用户私钥加密存储到数据库
```

### 3. 数据库更新

**新增字段：**

```sql
ALTER TABLE certificate

ADD COLUMN user_private_key_encrypted TEXT COMMENT '用户私钥（PEM 格式，加密存储）',
ADD COLUMN key_algorithm VARCHAR(20) DEFAULT 'RSA' COMMENT '密钥算法',
ADD COLUMN key_size INT DEFAULT 2048 COMMENT '密钥长度';
```

## 🔧 使用场景

### 场景 1：用户数字签名

```
用户 A
├── 使用用户 A 私钥签名文件
└── 生成数字签名

├── 获取用户 A 证书（包含用户 A 公钥）
├── 使用用户 A 公钥验证签名
└── 确认文件确实由用户 A 签署
```

### 场景 2：加密通信

```
发送方
├── 获取用户 A 证书（包含用户 A 公钥）
├── 使用用户 A 公钥加密数据
└── 发送加密数据给用户 A

用户 A
└── 使用用户 A 私钥解密数据
```

### 场景 3：身份认证

```
用户 A
├── 使用用户 A 私钥签名挑战数据
└── 发送签名给服务器

服务器
├── 获取用户 A 证书
├── 使用用户 A 公钥验证签名
└── 确认用户 A 身份
```

## 🔐 安全性说明

### 用户私钥保护

**当前实现：**
- ✅ 用户私钥存储在数据库中
- ✅ 建议：生产环境应加密存储
- ✅ 建议：使用 HSM 或密钥管理服务

**建议增强：**
1. 使用 AES 加密私钥后存储
2. 加密密钥由用户密码派生
3. 或使用硬件安全模块（HSM）

### 密钥长度

**当前配置：**
- RSA 2048 位

**建议：**
- 高安全场景：RSA 4096 位
- 或改用 ECC（更短的密钥，更高的安全性）
