# CA证书管理系统 - 亮色配色方案系统

## 方案概述

本系统采用**亮色配色方案**，完全排除深色系色彩，确保符合 **WCAG 2.1 AA级**以上的对比度标准，保证文本与背景的可读性。

---

## 实施指南

### 1. CSS变量配置

在 `design-system.css` 中添加以下变量定义：

```css
:root {
  /* 配色方案选择：scheme-1(清新蓝调) | scheme-2(温暖琥珀) | scheme-3(科技青柠) */
  --color-scheme: scheme-1;
  
  /* 主色 */
  --color-primary: #3B82F6;
  --color-primary-light: #60A5FA;
  --color-primary-dark: #2563EB;
  
  /* 辅助色 */
  --color-accent: #F97316;
  --color-accent-light: #FB923C;
  --color-accent-dark: #C2410C;
  
  /* 状态色 */
  --color-success: #10B981;
  --color-warning: #F59E0B;
  --color-error: #EF4444;
  --color-info: #06B6D4;
  
  /* 背景色 */
  --color-bg-primary: #FFFFFF;
  --color-bg-secondary: #F8FAFC;
  --color-bg-tertiary: #F1F5F9;
  --color-bg-card: #FFFFFF;
  
  /* 文本色 */
  --color-text-primary: #0F172A;
  --color-text-secondary: #334155;
  --color-text-tertiary: #64748B;
  --color-text-muted: #94A3B8;
  
  /* 边框色 */
  --color-border: #E2E8F0;
  --color-border-hover: #CBD5E1;
  
  /* 阴影 */
  --shadow-sm: 0 2px 8px rgba(0, 0, 0, 0.08);
  --shadow-md: 0 4px 20px rgba(0, 0, 0, 0.12);
  --shadow-lg: 0 8px 40px rgba(0, 0, 0, 0.16);
  --shadow-glow: 0 0 20px rgba(59, 130, 246, 0.2);
}
```

## 实施步骤

### 第一步：选择配色方案
根据项目需求选择一套配色方案，推荐使用**方案一：清新蓝调**。

### 第二步：更新CSS变量
在 `design-system.css` 中更新 `:root` 选择器内的所有颜色变量。

### 第三步：更新组件样式
根据新的配色方案调整所有组件的颜色引用。

### 第四步：测试对比度
使用工具验证所有颜色组合的对比度是否符合WCAG 2.1 AA级标准。

### 第五步：文档更新
更新所有相关文档和设计规范。
