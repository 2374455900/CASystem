## 🎯 配色应用场景规范

### 主色应用 (#3B82F6)

- 主按钮和主要行动号召

**不推荐使用：**
- 大面积背景色
- 文本主要颜色（对比度过低）

**使用场景：**
- 警告和通知
- 次要按钮和操作
- 时间敏感信息

**不推荐使用：**
- 主要文本颜色
- 大面积背景色

- 成功消息和确认

**错误状态 (#EF4444)：**
- 错误消息和警告

## 📊 实施指南

### 1. 设计系统集成

所有新组件应使用 CSS 变量定义的颜色：

```css
/* 主色 */
var(--color-primary)

/* 辅助色 */
var(--color-accent)

/* 背景色 */
var(--color-bg-primary)
var(--color-bg-secondary)
var(--color-bg-tertiary)

/* 文本色 */
var(--color-text-primary)
var(--color-text-secondary)
var(--color-text-tertiary)

/* 边框 */
var(--color-border)
var(--color-border-hover)
```

### 2. 组件开发规范

**按钮组件：**
- 主按钮：使用主色渐变
- 次要按钮：使用中性色背景
- 危险按钮：使用红色强调色

**表单组件：**
- 输入框背景：使用浅灰或纯白
- 边框颜色：使用中灰
- 聚焦状态：使用主色边框和阴影

**卡片组件：**
- 背景：使用纯白
- 边框：使用浅灰
- 悬停：使用中灰背景

### 3. 文本可读性标准

**正文文本：**
- 文本颜色：#334155 或 #0F172A
- 背景颜色：#FFFFFF
- 对比度：≥ 15:1 (AAA级)

**辅助文本：**
- 文本颜色：#64748B
- 背景颜色：#F8FAFC
- 对比度：≥ 7:1 (AA级)

**链接文本：**
- 默认颜色：#3B82F6
- 悬停颜色：#2563EB
- 对比度：≥ 4.5:1 (AA级)

### 4. 响应式适配

所有颜色方案在不同屏幕尺寸下保持一致：

- **桌面端 (≥ 1024px)：** 使用完整配色方案
- **平板端 (768px - 1023px)：** 保持配色，调整间距
- **移动端 (< 768px)：** 保持配色，优化对比度

## 📚 参考资源

### WCAG 2.1 标准

- **AA级要求：**
  - 正文文本：≥ 4.5:1 对比度
  - 大型文本（18pt+）：≥ 3:1 对比度
  - UI组件：≥ 3:1 对比度
  - 图形元素：≥ 3:1 对比度

- **AAA级要求：**
  - 正文文本：≥ 7:1 对比度
  - 大型文本（18pt+）：≥ 4.5:1 对比度
